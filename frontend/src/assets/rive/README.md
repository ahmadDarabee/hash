# Rive assets (source)

Source `.rev`/`.riv` project files for the Wojak character can live here for
version control. The runtime asset that the app loads is copied to
`frontend/public/rive/wojak.riv`.

See `frontend/public/rive/README.md` for the required state machine and inputs,
and `docs/WOJAK_INTEGRATION.md` for how events drive the character.
